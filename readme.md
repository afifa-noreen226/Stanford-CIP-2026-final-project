*Student Manager App* 🎓

A lightweight, command-line interface (CLI) Python application to manage student records and track their academic results. This project is ideal for beginners looking to understand basic Python concepts like dictionaries, loops, conditional statements, and user input handling.

---

## 🚀 Features

* *Add Students:* Easily register new students along with their marks.
* *View Records:* Display a complete list of all registered students and their scores.
* *Check Results:* Instantly check if a specific student has *PASSED* or *FAILED* based on their marks.
* *Error Handling:* Basic validation for missing student records and invalid menu choices.

---

## 🛠️ Prerequisites

To run this application, you only need *Python 3.x* installed on your system. No external libraries or dependencies are required.
